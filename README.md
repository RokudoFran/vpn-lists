# vpn-lists

Автоматически обновляемые списки IP-подсетей и доменов для выборочной маршрутизации через VPN на роутере MikroTik (RouterOS).

Идея простая: через туннель идёт только то, что недоступно напрямую (заблокированные и ушедшие из РФ сервисы, нужные CDN), а всё остальное, особенно российские сервисы, ходит напрямую.

## Как это работает

```
services.yaml + manual.txt
        │
        ▼
collector.py  (GitHub Actions, каждый день в 04:00 МСК)
        │   ├─ префиксы по ASN из RIPEstat
        │   ├─ официальные списки IP CDN (Cloudflare, CloudFront, Fastly)
        │   └─ ручные подсети, не покрытые автосбором
        ▼
lists/*.txt  ──►  роутер MikroTik забирает списки по raw-ссылке
```

1. **`services.yaml`** описывает сервисы: ASN, источники IP и домены. Сервис можно выключить через `enabled: false`, не удаляя описание.
2. **`collector.py`** собирает IPv4-префиксы, отбрасывает приватные и IPv6, схлопывает пересекающиеся подсети.
3. **`manual.txt`** хранит подсети, добавленные вручную. Всё, что уже покрыто автосбором, скрипт выкидывает сам, а непонятные остатки с владельцем по whois пишет в `reports/leftover.md`.
4. **GitHub Actions** (`.github/workflows/collect.yml`) запускает сбор по расписанию, вручную или при изменении конфигов и коммитит результат, только если списки поменялись.

## Выходные файлы

| Файл | Что внутри |
|---|---|
| `lists/vpn_ipv4.txt` | IPv4-подсети для маршрутизации через VPN (одиночные адреса без `/32`, как хранит RouterOS) |
| `lists/domains_vpn.txt` | домены, которые нужно пускать через VPN |
| `lists/domains_direct.txt` | домены, которые всегда идут напрямую (`no_vpn`) |
| `lists/version.txt` | SHA-256 от содержимого списков: роутер обновляется только когда он меняется |
| `reports/leftover.md` | ручные подсети, которые не покрывает автосбор, с AS и владельцем |

Списки содержат только данные, без команд RouterOS: роутер сам их скачивает, проверяет и применяет.

## Защита от поломок

- Каждый запрос к источникам повторяется до 3 раз; если источник недоступен, скрипт завершается без изменений.
- Если собралось меньше 50 префиксов, списки не перезаписываются, чтобы роутер не получил пустой или обрезанный список.
- Правило для `no_vpn` стоит в mangle выше правила `vpn_only`, поэтому банки, госуслуги и маркетплейсы не уходят в туннель, даже если их адреса попали в общий диапазон.

## Как добавить сервис

```yaml
services:
  example:
    enabled: true
    asn: [12345]            # префиксы подтянутся из RIPEstat
    domains: [example.com]  # попадут в domains_vpn.txt
```

ASN перед добавлением стоит проверить на [bgp.he.net](https://bgp.he.net).

## Локальный запуск

```bash
pip install pyyaml
python collector.py
```
